Privacy Policy

Last updated: 2026-10-04

gmail-agent is a personal tool used only by its developer, Joshua Kim (goodgrief4077@gmail.com), on his own Google account.

Data accessed

With the gmail.readonly scope, the app reads the owner's own Gmail messages to classify them and write a daily summary.

Use and storage

Mail content is processed on the owner's own private server and a local AI model. It is stored only on the owner's own devices. It is not sold, shared, or disclosed to third parties, and it is not used for advertising or to train AI models.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
