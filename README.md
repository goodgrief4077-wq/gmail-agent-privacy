# gmail-agent-privacy

Public web pages for a personal Gmail tool ("gmail-agent"): home, privacy policy and terms of service.

## What it is for
Google's OAuth consent screen requires public URLs for an app's home page, privacy policy and terms. These pages are those URLs. The tool itself is private and single-user.

- Live site: https://goodgrief4077-wq.github.io/gmail-agent-privacy/
- Files: `index.html`, `privacy.html`, `terms.html`

## Keep in mind
- Do not make this repo private or delete it while the Gmail API is in use; the Google consent screen links to these pages.
- Edit the pages here; GitHub Pages rebuilds from the main branch.
